# WealthOS mobil

Kursansicht für iPhone und iPad zu WealthOS: Depots mit Wert und Veränderung zum Vortag. Die Kurse kommen direkt von onvista.

**Dieses Repository enthält nur Code, keine Daten.** Die Bestände (WKN, Stück) kommen einmalig per QR-Code oder Link aus WealthOS (Einstellungen → 📱 Mobil). Sie stehen im Link hinter dem `#`. Dieser Teil wird nie an den Server gesendet. Danach liegen die Bestände nur im Browser des Geräts.

- `index.html`: die App, eine Datei mit HTML, CSS und JavaScript
- `icon.png`: Symbol für den Home-Bildschirm

Aufruf: https://heyneca-stack.github.io/wealthos-mobil/
